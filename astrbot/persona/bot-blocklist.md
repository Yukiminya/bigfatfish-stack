# 机器人黑名单与过滤规则（迁移到 AstrBot 用）

DSH 里那套过滤是改代码实现的（`onebot.mjs` 号段 + `runtime.mjs` 的 `is_robot` 查询）。
AstrBot 没有同样的代码，能用的替代方案有两层：

## 第一层：黑名单（AstrBot 的「屏蔽用户」/ 群聊白名单）

把这些 QQ 号加进 AstrBot 的屏蔽列表（插件面板里的「黑名单 / block」或会话过滤配置）：

```
2854196310   Q群管家
2854213916   一念
3889042293   火花Official
3889006601   幻梦（今日老婆）
```

另外这个群最好直接不接：

```
495798092    勇闯北京 解救亦凡（已退群，别再加回）
```

## 第二层：号段规则（如果 AstrBot 用的插件支持正则/前缀过滤）

QQ 机器人基本都在这两个号段，能按前缀挡就一次挡完：

```
2854xxxxxx   腾讯官方服务号（Q群管家、群签到、群助手…）
3889xxxxxx   QQ 机器人平台下发的号（火花Official、今日老婆…）
```

## 第三层：QQ 自己给的 `is_robot` 标记

NapCat 的 `get_group_member_info` 返回里有 `is_robot: true/false`，
真人 `false`，机器人 `true`。如果 AstrBot 那边有能扩展的 OneBot 中间件/插件，
可以照 DSH 的做法：收到群消息先查一次成员信息，`is_robot === true` 就直接丢弃
（结果按「群:人」缓存一小时；查询失败当人处理，别吞真人消息）。

## 已知会被挡掉/需要留意的

- `@全体` 公告类消息基本都是机器人发的，挡掉不影响正常聊天。
- 号段外又没 `is_robot` 标记的个人脚本机器人，只能手动加黑名单。
